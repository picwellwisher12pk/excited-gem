Spatial Tab Management

Effortless Multi-Window Organization with Window Grid View

Working across multiple screens or project windows? Excited Gem transforms disconnected windows into an organized visual grid where tabs can be dragged and dropped between windows seamlessly.

  • ✓ Cross-Window Drag & Drop: Move tabs between any active window cards with real-time drop indicator guides.
  • ✓ Per-Window Live Filtering: Type directly in any window's title bar to filter tabs in that window without affecting others.
  • ✓ Sleek Incognito Styling: Private and incognito browsing sessions are immediately distinct with specialized dark-tinted tiles.
  • ✓ Window Batch Operations: Discard inactive tabs, save window as a session, save as a bookmark list, or close with Ant Design confirmation.

Get Started in 3 Quick Steps

Build from source with Bun or load unpacked directly into Chrome.

1

Clone & Install

Clone the repository and install all development dependencies using Bun:

git clone https://github.com/picwellwisher12pk/excited-gem.git
cd excited-gem && bun install
2

Build Extension

Run the Plasmo build pipeline to compile production Manifest V3 assets:

bun build
3

Load in Chrome

Open chrome://extensions, enable Developer mode, click Load unpacked, and select:

build/chrome-mv3-prod
